### Valuation and market research tools

I define what a tool should do, how to check that it is right, and then test it. The code is written with AI coding agents.

**Projects**
- **Consilio**: DCF and trading-multiples engine for SME advisory work. Exports open Excel formulas and flags when a DCF is not applicable. *(private)*
- **MoirAI → Talos → Kairos**: three paper-trading systems, each designed on the measured results of the one before. *(private)*
- **[Market Ecology Simulator](https://github.com/TjarkAI/market-ecology-simulator)**: agent-based stock market model, checked against six stylised facts of real markets.

**Approach:** set the acceptance criteria before building, measure against a baseline, and report results that do not work as well as those that do.
